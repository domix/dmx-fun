# Deliveries

One section per delivery, written the same day while it is fresh. This is the input for the last step of
the talk plan (issue #561): questions that came up go back into the deck (the Q&A slide and the notes) and,
when they reveal a gap, into the tutorial (#560) or a new issue. Also add the event to
`site/src/data/talks/2026-signatures-you-can-trust.md` (`events`, and `status: delivered`) so the Talks
page shows it.

## Template

```markdown
## <Event>, <City>, <YYYY-MM-DD>

- Audience: ~N people; mostly <backend Java / mixed / students>. Language: EN | ES.
- Demo: live | recorded (why).
- Timing vs the minute marks: <block that ran long / short, by how much>. Backup slides used: yes | no.

### Questions asked

| Question | Answered from | Follow-up |
|---|---|---|
| <as asked> | Q&A slide / notes / improvised | none / deck: <slide> / tutorial: <chapter> / issue #N |

### What to change

- Deck: <slide, what and why>
- Tutorial: <chapter, what and why>
- Issues opened: #N, #M

### What landed well

- <the moment that got the reaction; keep it>
```
