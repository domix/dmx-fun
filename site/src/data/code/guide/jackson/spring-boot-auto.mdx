```java
// With fun-spring-boot and a dmx-fun Jackson module on the classpath
// (fun-jackson3 on Spring Boot 4, fun-jackson2 on Spring Boot 3), DmxFunModule is
// registered automatically as a bean. No @Bean declaration needed — Spring Boot's
// JacksonAutoConfiguration discovers all module beans and applies them to the mapper.

// Controller just works: Jackson serializes Result, Option, Try transparently.
@GetMapping("/users/{id}")
public Result<User, ApiError> getUser(@PathVariable Long id) {
    return userService.findById(id);
    // → {"ok":{"id":1,"name":"Alice"}}   or   {"err":{"code":"NOT_FOUND"}}
}

// Override: declare your own DmxFunModule bean when you need customization.
// The auto-configuration backs off automatically (ConditionalOnMissingBean).
@Bean
public DmxFunModule dmxFunModule() {
    return new DmxFunModule(); // add custom serializers here if needed
}
```

```properties
# Opt out of the Jackson auto-configuration (enabled by default); one property per line
dmx.fun.jackson3.enabled=false
dmx.fun.jackson2.enabled=false
```
